VADANAM — CUSTOM BRANDING FOLDER
================================

Drop your own images into this folder to replace the built-in logo and
workspace icons. Both .png and .jpg work (.png is tried first).
No code changes needed — if a file is missing, the default icon shows.

File names (square images, transparent .png recommended):

  logo.png  / logo.jpg      -> Vadanam logo (top of sidebar, mobile bar,
                               homepage, sign-in, footer)       ~ 96x96px+
  chat.png  / chat.jpg      -> Team Chat icon (sidebar + bottom bar)
  files.png / files.jpg     -> Shared Files icon
  roadmap.png / roadmap.jpg -> Roadmap icon
  tasks.png / tasks.jpg     -> Tasks icon (sidebar + bottom bar)
  mentor.png / mentor.jpg   -> AI Mentor icon (sidebar + bottom bar)
  timer.png / timer.jpg     -> Timer icon (sidebar + bottom bar)
  settings.png / settings.jpg -> Settings icon

Tips:
  - Icons are shown at ~18-36px; ~48x48px source size is plenty.
  - After adding/replacing files: refresh in dev, or run `npm run build`
    for production.
